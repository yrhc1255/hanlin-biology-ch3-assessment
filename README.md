# 翰林自然 3-3～3-4 課後評量

依《115 國中自然 1 上備課用書》第 82～92 頁設計，20 題單選題，每題 5 分、滿分 100 分。

學生填寫班級、座號與姓名後作答。交卷可查看解析，同時將作答送至 Google Apps Script；伺服器重新計分並寫入教師私人 Google 試算表。成功訊息必須收到伺服器確認後才顯示；失敗時可重試。待傳資料暫存於本分頁，關閉分頁即清除。

成績表每位學生一列，保留最新與最高分；「作答紀錄」保留每次提交。事件識別碼防止重試重複計算。

## GAS

`gas/Code.gs` 是接收服務原始碼，`gas/appsscript.json` 是部署資訊。複製 `PrivateConfig.example.txt` 的內容建立私有 `PrivateConfig.gs` 後，填入自己的試算表 ID 與管理用隨機字串。實際設定不應提交 Git，教師成績表也不應公開分享。

公開端點只提供服務狀態與提交回覆，不提供全班成績查詢。`testStatus` 與 `cleanupTests` 僅供持有私有管理字串者查核／清理明確標示的測試資料。

原始教材 PDF 與學生資料未包含在此儲存庫。
